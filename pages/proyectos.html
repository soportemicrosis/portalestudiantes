Mini HRM

Aplicación web diseñada como un sistema ligero de gestión de recursos humanos. El objetivo principal fue practicar arquitectura backend, separación de responsabilidades y persistencia de datos en un contexto administrativo real.

¿Qué resuelve?

  • Gestión básica de colaboradores
  • Registro de información laboral
  • Organización de datos administrativos

Tecnologías

  • .NET / C#
  • Web API
  • SQL Server

Estado: En pausa. Proyecto conservado como referencia y portafolio técnico.

Tracking de Actividades

Proyecto enfocado en el registro y seguimiento de actividades. Nació como una exploración práctica de APIs, modelos de datos y visualización básica de información.

Objetivo

  • Registrar actividades de forma estructurada
  • Visualizar métricas simples
  • Practicar diseño de APIs REST

Tecnologías

  • .NET / C#
  • API REST
  • SQL Server

Estado: En pausa. Proyecto documentado para futura reactivación.
